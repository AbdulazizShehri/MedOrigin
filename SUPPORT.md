# MedOrigin support

MedOrigin is community-developed research software, **not a clinical product**.
No medical advice, diagnosis, production EHR support, or real-patient-data support
is provided.

| Need | Where to go |
| --- | --- |
| Ask a setup or usage question | [GitHub Discussions](https://github.com/AbdulazizShehri/MedOrigin/discussions) |
| Report a reproducible defect | [Bug report](https://github.com/AbdulazizShehri/MedOrigin/issues/new/choose) |
| Propose a new feature or improvement | [Discussions](https://github.com/AbdulazizShehri/MedOrigin/discussions) and [Issues](https://github.com/AbdulazizShehri/MedOrigin/issues) |
| Contribute code, tests, or docs | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a vulnerability or privacy exposure | [Private reporting](SECURITY.md) |
| Understand research/clinical limitations | [README.md](README.md) and [governance](GOVERNANCE.md) |

Before asking a question, read the [getting-started instructions](README.md#get-started)
and [documentation index](docs/README.md). When reporting a reproducible issue,
include the commit, operating system, Python version, commands and sanitized
synthetic inputs. Do not post PHI, secrets, access tokens, or sensitive
clinical materials.

There is no guaranteed response or commercial support SLA. Volunteers and
maintainers triage public reports according to safety, reproducibility and
available capacity; a PR needs its required checks and governance approvals
before merge.
