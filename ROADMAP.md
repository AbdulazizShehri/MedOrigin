# MedOrigin Roadmap

This page documents public status and evidence boundaries; it is not an unpublished strategic or engineering roadmap. Internal priorities, unreleased model choices, vendor studies, timelines, budgets, and implementation plans are not maintained in this public repository.

## Public status

MedOrigin is public Apache-2.0 research software. For verifiable changes see [RELEASES.md](RELEASES.md), [CHANGELOG.md](CHANGELOG.md), and Git history. Community contributions follow [GOVERNANCE.md](GOVERNANCE.md), [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).

## Scope and scientific integrity

The project remains synthetic-only research software, not a medical device. This page does not authorize real-patient information, clinical deployment, autonomous diagnosis, model training or promotion, external package publication, or new release tags.

Scientific experiment protocols and previously published evidence may remain publicly inspectable where required for reproducibility. The former roadmap was already publicly published; previous Git commits, forks, clones, and archives may still contain its full text. Private storage cannot retroactively guarantee secrecy for previously published material.
