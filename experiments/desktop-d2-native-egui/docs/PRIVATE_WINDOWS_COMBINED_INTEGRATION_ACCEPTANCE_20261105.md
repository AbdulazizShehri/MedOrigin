They do NOT prove full HL7 FHIR R4 conformance, terminology, profiles, FHIRPath, patient safety, clinical review, real patient consent, production clinician identity/RBAC, authenticated OS process chain, packet/DNS network confinement, production key lifecycle/recovery, accessible production installer, Windows code signing, independent security/clinical review, or vulnerability remediation.
