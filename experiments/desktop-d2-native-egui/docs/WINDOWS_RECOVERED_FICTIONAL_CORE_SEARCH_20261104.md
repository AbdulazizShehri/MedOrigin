# Native D2: search source-recovered fictional encrypted Core resources

**2026-11-04. Private stacked Draft on #941. Source-derived fictional identities ONLY; not a patient search or clinical application.**

## Product-facing functionality

After a genuine fixed three-resource imaginary FHIR Core encrypted Workspace readback, the native Rust D2 GUI now presents an **in-memory search field** and two directly selectable search shortcuts in its real recovered resource explorer. Users can search the redacted **resource type, fictional resource ID or exact source-derived urn:uuid fullUrl**, combined with existing All/Observation/Patient/Encounter type filters. The GUI shows the current normalized search and count of matching resource identities. Direct shortcuts `Search recovered source: Patient`, `Search recovered source: Encounter`, and `Clear recovered search` support keyboard/accessibility-driven UI interactions; the text field is limited to **one 64-byte ASCII alphanumeric/hyphen/colon token**, case-insensitive. There are **no network lookups, raw resource content, dates, medical codes, notes, external FHIR imports or saved search histories**.

Changing a search clears selected record and all ephemeral Back navigation history, to prevent stale details under a hidden resource. Selecting any source-derived record outside the current search/type filter is refused and clears the fictional readback evidence. Type filter changes retain the search (AND intersection); verified incoming/outgoing FHIR-shaped relationship navigation resets both the type filter and query to All, preserving the actual selected target and bounded 16-hop Back chain. Clearing the entire fictional output or opening another source resets the search. Unreviewed input (non-ASCII, control, whitespace within the token, symbols outside the allowlist or length greater than 64 bytes) is **fail-closed**, discards the input, selection, history and entire fictional readback (not a clinical behavior claim). The UI explicitly warns not to enter real patient information.
