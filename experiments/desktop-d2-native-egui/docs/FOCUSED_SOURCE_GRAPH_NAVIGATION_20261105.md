# D2 focused Workspace — interactive source-linked reference graph and navigation history

**2026-11-05. Owner-private stacked Draft based on #958. FICTIONAL source only, NO PHI or clinical approval.**

## Product behavior

The native focused Workspace already opens the reviewed fake Core projection directly and presents a filterable resource list, but previously rendered links as read-only URN text. Users navigating any linked record workspace need to follow references, see which resource points to the current one, and return to earlier context without losing orientation. This slice adds **real clickable source-linked relationships and bounded navigation history directly inside the focused native egui Workspace**, without requiring the separate developer inspector.

After selecting an imaginary Patient/Encounter/Observation, the native detail now shows the exact source-derived incoming/outgoing link counts and clickable **Focus: Follow outgoing [field] to Type/id** and **Focus: Open incoming Type/id via [field]** controls. Incoming edges are computed only by comparing the exact source-projected URNs already recovered from Core; the UI never uses an independent patient database or guesses references. It also exposes **Focus: Verified navigation trail N of 16 steps**, clickable **Focus: Jump history step: Type/id** to source-verified ancestors, and **Focus: Back along verified path**. This corrects the old misleading Back to patient label, which could instead return to Encounter or Observation. Navigation across source-linked resource types resets type/keyword filters to All so the destination remains visible. Changing a filter or search still clears selection/history. No invented chronology, diagnoses, events, dates or clinical relationship values.

The UI action dispatch explicitly reuses the existing readback source navigators: `follow_encrypted_readback_link`, `follow_encrypted_readback_incoming`, `jump_encrypted_readback_history` and `back_encrypted_readback_resource`. The focused screen revalidates the exact three-record imaginary source graph each frame before showing actions. Missing/dangling/mismatched links and invalid history indices fail closed by discarding the admitted source instead of choosing another record. The 16-step bound is unchanged. The new buttons are accessible as native UIA/AX controls. No Rust crate, network/process access, arbitrary file input, patient import or privilege change.
