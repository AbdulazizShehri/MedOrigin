# Windows private one-click fictional Core Workspace launcher

**2026-11-05. Private stacked Draft on #950; imaginary records only. No PHI, clinical use or publication.**

## Product-facing UX improvement

The existing offline portable Windows D2 Desktop could already open a real fixed fictional Core AES-256-GCM Workspace and native Rust GUI, but users had to supply the approved Python executable, cryptography directory and exact executable hash on every run. A new *one-time source-only installer* checks an EXISTING fully attested portable kit and the exact locally approved Python executable SHA256, then writes a fixed-name **Start-MedOrigin-Fictional-Desktop.cmd** under the current user's LOCALAPPDATA/MedOrigin-D2-Private-Developer-QA directory. The developer can subsequently double-click the generated CMD file to open the same native GUI and the same Windows-user-DPAPI protected *fictional* encrypted test vault. If absent, the original launcher initializes the fixed fictional vault once; subsequent runs only cold-reopen it. Existing or damaged vaults are never replaced or automatically deleted.

The generated CMD binds the precise approved Python/crypto paths, binary SHA256, portable kit and immutable fixed imaginary vault path. The helper disallows CMD metacharacters, percent expansion, command-line argument forwarding, UNC paths, symlink/junction ancestors, unapproved QA modes and overwriting an existing shortcut. It creates only its fixed private current-user folder and does not elevate, modify the registry/Start Menu, auto-start processes, install services, query a network, copy patient files or bypass a production key gate. The console is intentionally visible; closing the real native GUI completes the interactive invocation.

## One-time setup and normal launch

Use the previously attested offline historical Core+Workspace Wheel workflow to assemble the strict private portable kit. Run the **reviewed exact Windows Python process** with scripts/install_windows_private_fictional_desktop_entry.py and the options: --kit <PRIVATE_PORTABLE_KIT>, --python <APPROVED_PYTHON_EXE>, --crypto-site <LOCAL_CRYPTOGRAPHY_SITE_PACKAGES>, --python-sha <EXACT_SHA256>. No network or elevation. Then double-click LOCALAPPDATA/MedOrigin-D2-Private-Developer-QA/Start-MedOrigin-Fictional-Desktop.cmd. The original portable launcher re-attests every reviewed file and all 290 installed Core source files on each run, not just during setup. Any changed Python, Core file, GUI, manifest, cryptography/cffi version or generated source projection refuses. The same fixed user DPAPI test key and audit anchor are retained on subsequent valid starts.

Optional separate *QA-only* setup calls with --qa-mode uia or --qa-mode auto-close create fixed filenames QA-MedOrigin-Fictional-Desktop-UIA.cmd and QA-MedOrigin-Fictional-Desktop-AutoClose.cmd. Normal user-facing shortcut never auto-closes the GUI. None of the generated local CMD files, absolute user paths, DPAPI blobs, SQLite store, Wheel files or GUI binaries is committed to GitHub.
