# Copied-source attribution — native desktop D2 experiment

This experimental source adapts the entry-point and application structure from
[emilk/eframe_template](https://github.com/emilk/eframe_template)
(accessed 2026-10-29), authored by Emil Ernerfeldt and contributors,
offered under **MIT OR Apache-2.0**. The template's source was modified
for MedOrigin's four fictional D0 SHA-256 vectors, to remove the Web target,
persistence, external navigation and telemetry. Original author/license
notices are preserved here rather than misrepresenting donor code as wholly new.

License option selected for adapted portions: **Apache-2.0**.
MedOrigin experimental source is likewise Apache-2.0.
The original Apache-2.0 text is in the repository root `LICENSE`
(if this root uses a different file, check that before distributing).
All transitive crate licenses still require independent review before use
in an installer; no distribution is authorized.
